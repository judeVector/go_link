# go_link

A simple social API built with Go that lets users connect, share, and interact.  
This project demonstrates modern Go web development using the **chi** router along with the standard `net/http` package.

## Features

- User endpoints (create & retrieve users)
- Routing powered by [chi](https://github.com/go-chi/chi)
- Clean HTTP server setup with `http.Server`
- Foundation for a social platform (users, future posts, follows, etc.)

## Tech Stack

- Go 1.27
- [chi](https://github.com/go-chi/chi) — lightweight, idiomatic router
- Standard library (`net/http`)
